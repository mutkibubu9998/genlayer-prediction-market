How resolution works: after the deadline anyone can call resolve — the leader validator fetches the evidence URL and asks an LLM for a strict JSON verdict (YES / NO / VOID); every validator independently re-fetches and re-runs the LLM, and the outcome is accepted only on exact agreement. Winners claim pro-rata from the pot; VOID (or no winning stakes) refunds everyone.
